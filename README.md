## Description

Report automation in **Google Sheets** for a healthcare clinic. The dashboard provides comprehensive tracking of appointment management, medical resource evaluation, and patient satisfaction.

## Tasks

- **Appointment Management** — Tracking and analysis of patient appointments, scheduling efficiency, and no-show rates.
- **Medical Resource Evaluation** — Assessment of medical resources utilization, staff allocation, and capacity planning.
- **Patient Satisfaction** — Monitoring patient feedback, satisfaction scores, and service quality metrics.

## Tools

- **Google Sheets** — Data storage, formulas, and dashboard visualization
- **Google Apps Script** — Automation of report generation and data processing
